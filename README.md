## 📋 Описание

**Automation** — это коллекция полезных скриптов для автоматизации различных повседневных задач. От управления файлами до веб-тестирования, от работы с Excel до контроля умного дома — здесь найдется инструмент для каждой задачи.

> **Примечание**: Некоторые скрипты являются простыми примерами (например, [Send-email](send-email/email.py)), но они служат отличной основой для более сложных решений.

> Скрипты, помеченные символом **(X)**, созданы как фундамент для более сложных автоматизированных систем, таких как управление расходами, доходы, selenium-тестирование и другие.

## 📦 Доступные инструменты

### 📥 **DL-file** (X)
**Загрузчик файлов**

Автоматическая загрузка файлов из интернета.

---

### 📊 **Excel** (X)
**Работа с Excel файлами**

#### 💰 Expenses (X)
Добавляет бизнес и личные расходы в Excel.
> **Примечание**: Текущая версия требует ручного ввода расходов, которые затем автоматически добавляются в Excel. Это базовая версия, которую можно расширить под свои нужды.

#### 📈 Graph (X)
Создание графиков в Excel для визуализации данных.

#### 💵 Income (X)
Добавляет доходы в Excel.
> **Примечание**: Текущая версия требует ручного ввода доходов, которые затем автоматически добавляются в Excel. Это базовая версия, которую можно расширить под свои нужды.

---

### 💡 **Hue-light** (X)
**Управление умными лампами Philips Hue**

Контроль освещения через API Philips Hue.

---

### 🔧 **Git-commands**
**Автоматизация Git операций**

Автоматизирует выполнение команд Git:
- `clone` — клонирование репозиториев
- `commit` — создание коммитов
- `branch` — работа с ветками
- `pull` — получение изменений
- `merge` — слияние веток
- `blame` — просмотр авторов строк

---

### 🌐 **Monitor-website**
**Мониторинг веб-сайтов**

Отслеживает доступность веб-сайта. Если сайт недоступен:
- 📧 Отправляет email-уведомление
- 🔊 Воспроизводит звуковой сигнал

---

### 🖱️ **Move-cursor**
**Управление курсором**

#### Cursor
Перемещает курсор каждые 10 секунд (полезно для предотвращения блокировки экрана).

#### Piano Tiles
Автоматизированный бот для игры Piano Tiles от [adhirajpandey](https://github.com/adhirajpandey).

---

### 📁 **Organize-files**
**Организация файлов**

Автоматически сортирует файлы по типам и перемещает их в соответствующие папки:
- 🖼️ Изображения
- 🎵 Аудио файлы
- 📄 Текстовые файлы
- 🎬 Видео
- 📦 Архивы (сжатые файлы)

---

### 🔴 **Reddit**
**Работа с Reddit**

Эффективный перенос подписок с одного аккаунта Reddit на другой:

#### Extract
Извлечение списка подписок из аккаунта ([источник скрипта](https://github.com/adhirajpandey)).

#### Join
Автоматическое присоединение к подreddit'ам ([источник скрипта](https://github.com/adhirajpandey)).

---

### 🐙 **Repo**
**Создание GitHub репозиториев**

Автоматическое создание приватных или публичных репозиториев на GitHub.
> Использует Selenium, но можно легко переключиться на GitHub API.

---

### ⏰ **Scheduler** (X)
**Планировщик задач**

Выполнение запланированных задач:
- 📧 Открытие email
- 💻 Выключение компьютера
- И многое другое...

---

### 🧪 **Selenium Testing** (X)
**Автоматизированное тестирование**

#### Cross Browser
Кросс-браузерное тестирование веб-приложений.

#### Login Form
Тестирование форм входа на:
- GitHub
- Stack Overflow
- Twitter

Генерирует подробный отчет о результатах.

#### Search
Тестирование функции поиска:
- Поиск `Python` на GitHub
- Поиск на Stack Overflow
- Поиск на Amazon

Генерирует отчет о результатах.

#### Sign Up SO
Тестирование процесса регистрации на:
- Stack Overflow
- Gmail
- GitHub

Генерирует отчет о результатах.
